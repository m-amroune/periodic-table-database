#  Project : Periodic Table Database

##  About the Project

**Objective** : Build a PostgreSQL database that stores information about chemical elements from the periodic table. This project is part of FreeCodeCamp’s Relational Database Certification and is completed in a Linux environment using PostgreSQL and Bash.

##  Project Tasks

- Create a PostgreSQL database named `periodic_table`
- Define a table `elements` with columns for `atomic_number`, `symbol`, and `name`
- Define a table `properties` with columns for atomic properties such as `atomic_mass`, `melting_point`, `boiling_point`, and `type`
- Use appropriate constraints (`PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, etc.)
- Insert data for at least 10 elements
- Write a shell script that:
  - Accepts an atomic number, symbol, or name as input
  - Queries the database and displays element information in a formatted message
  - Handles invalid input gracefully
- Pass all automated tests provided by CodeRoad
